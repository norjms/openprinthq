PROTOCOL COMPATIBILITY
----------------------
OctoPrint — https://octoprint.org
  Copyright (C) Gina Häußge and the OctoPrint contributors. OpenPrintHQ contains
  NO OctoPrint code. It implements an OctoPrint-COMPATIBLE upload API so that
  slicers which already speak that protocol can send finished plates, and it
  reports an OctoPrint-style version string because clients test for it. This is
  interoperability, not affiliation, and no endorsement by the OctoPrint project
  is implied.


Moonraker -- https://github.com/Arksine/moonraker
  Copyright (C) Eric Callahan and the Moonraker contributors. OpenPrintHQ
  contains NO Moonraker code. It implements a Moonraker-COMPATIBLE file-upload
  endpoint so that tools which already speak that protocol can send a plate into
  the queue. This is interoperability, not affiliation, and no endorsement by
  the Moonraker project is implied.
